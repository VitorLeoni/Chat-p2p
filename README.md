# Chat-p2p
P2P Chat  secure, serverless peer-to-peer web chat built with vanilla JavaScript and WebRTC. Features end-to-end encryption (E2EE) using the Web Crypto API (ECDH + AES-GCM), automatic message self-destruction timers and Web Audio notification—all with zero external dependencies.

A minimalist direct chat web application (Peer-to-Peer), built purely in vanilla JavaScript, with no need for backend servers, databases, or third-party services for message traffic.

The project uses WebRTC DataChannels to establish a direct connection between browsers and the Web Crypto API.

Main Features
End-to-End Encryption (E2EE): Generation and exchange of ephemeral symmetric keys right upon connection via elliptic-curve Diffie-Hellman (ECDH + AES-GCM). Intercepted network traffic is completely unreadable.

"Self-Destruction" Mode: Messages feature a visible 5-minute countdown timer, after which they are erased from both the screen and the browser's memory.

Native Sounds (Web Audio API): Lightweight audio alerts generated by an internal browser synthesizer, triggered when a new message arrives and the tab is in the background.

Customizable Themes and Colors: Visual theme selector (Dark by default or Light) and custom accent color options for your messages. 

Simple Markdown Editor: Support for basic text formatting such as bold and italic with monospace font.

How It Works (Serverless Architecture)
Since WebRTC requires an initial signaling step for peers to find each other (exchanging Offer and Answer), the chat uses a method based on manually copied text codes:

The Host starts the conversation and copies their generated code.

The code is sent to the other participant through any channel.

The Guest pastes the code, generates a response, and sends it back to the Host.

Once the connection is established, all communication happens directly browser-to-browser (P2P).

How to Use Being a single file (.html):

1 - Download or clone this repository.

2 - Open the .html file directly in any modern browser (Chrome, Safari, Firefox, Edge).

Technologies Used

HTML5 & CSS3 (with native CSS variables for theme management)

WebRTC API (RTCPeerConnection and RTCDataChannel)

Web Crypto API (SubtleCrypto for native encryption)

Web Audio API (for notification sound synthesis)
